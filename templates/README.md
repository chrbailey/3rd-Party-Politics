# Templates

Copy, fill in, publish. Templates in this project are meant to be used verbatim by real campaigns.

- [`constituent-commitment.md`](constituent-commitment.md) — the signed, public promise a candidate makes to voters instead of a party platform. The core document of the whole project.

## Wanted (open an issue to contribute)

- Announcement post / speech (5-minute and 60-second versions)
- Town-hall format: agenda, ground rules, and the "hard question" segment
- First fundraising email: personal ask, transparent numbers, no dark patterns
- Volunteer captain one-pager
- Post-election scorecard: promises vs. outcomes, published win or lose
