# Code of Conduct

This project brings together people who disagree about almost everything in politics — except one thing: candidates should be able to run without a party, and voters should be able to judge them on what they commit to do.

To keep the work usable for everyone:

- Be respectful, specific, and constructive. Critique ideas, checklists, and sources — not people.
- No harassment, intimidation, or discrimination of any kind.
- No partisan campaigning here. This repo builds process infrastructure, not a platform.
- No posting private information about candidates, voters, donors, or contributors.
- Assume good faith first; ask for a source before assuming bad intent.

Maintainers may remove comments, issues, or contributions that violate this code, and may block repeat offenders. Decisions aim to be prompt, proportionate, and explained in public where possible.

Adapted in spirit from the Contributor Covenant, version 2.1.
