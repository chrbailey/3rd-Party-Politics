# Roadmap

The goal is not attention for its own sake. The goal is a working, party-free path from *credible person* to *on the ballot, funded, and heard* — repeatable in any district.

## v0.1 — Foundations (now)

- [x] Manifesto and non-negotiables in the README
- [x] Steering group charter with hard limits (`steering/`)
- [x] Candidate recruiting scorecard (`recruiting/`)
- [x] Constituent Commitment template (`templates/`)
- [x] Issue templates for state verification, district scoring, and candidate suggestions

## v0.2 — Ballot-access database

- [ ] One verified file per state in `ballot-access/states/`
- [ ] Every rule cited to an official Secretary of State / elections board source, with a `last_verified` date
- [ ] A single summary table: signatures, deadline, fee, and form for independent candidates, by state and office

**Definition of done:** a candidate in any state can answer "what exactly must I file, by when, with how many signatures?" from this repo alone — then confirm it in one click at the official source.

## v0.3 — First target districts

- [ ] Apply the district-targeting method to publish the first 25–50 scored districts
- [ ] Each district file: incumbent status, margin history, independent/unaffiliated voter share, ballot difficulty, known local talent pool

## v0.4 — Launch playbook, end to end

- [ ] Filing week checklist
- [ ] Compliance calendar generator (federal + state dates)
- [ ] Small-donor fundraising stack setup guide
- [ ] First-30-days distribution playbook (town halls, local media, podcasts, social)

## v1.0 — First steering cycle

- [ ] Steering group seated under the charter
- [ ] First recruited candidates publicly committed, using the Constituent Commitment template
- [ ] Support delivered as a service through one complete filing cycle, with a public post-mortem

## Explicitly out of scope — forever

- Registering as a political party or owning a ballot line
- Endorsing a shared policy platform
- Whipping votes, collecting dues, or disciplining candidates
- Owning candidate donor lists, data, or accounts
